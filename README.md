## Database Setup

To set up the project database:
1. Download the `flight_simulator.sql` file from [this link](https://drive.google.com/file/d/1P9RTrQdZuxeG7UjPsMM_ecBA87sjWvvw/view?usp=sharing).
2. Import it into your local database using **phpMyAdmin** or any SQL client.
3. After importing, you can start the application.
4. Edit .env file according to your database.
